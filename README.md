R35050 —— ESP32 系列 LED 灯带统一固件

项目概述

R35050 是一款面向 ESP32 系列芯片的统一固件，支持 ESP32-C3 / ESP32-S2 / ESP32-S3 三款主流芯片，实现了 WiFi 配网、局域网设备发现、多设备颜色同步、分布式快闪以及网页后台管理等完整功能。一份代码通吃三款芯片，烧录时只需在 Arduino IDE 中选择对应板型即可。


固件版本：1.6.0



支持的硬件

芯片型号	板型编号	灯带数据脚	板载灯引脚	AP 热点名称
ESP32-C3	1	GPIO5	无	Rcustom-5V3-Setup-esp32c3
ESP32-S2	2	GPIO33	无	custom-5V3-Setup-esp32s2
ESP32-S3	3	GPIO4	GPIO48	custom-5V3-Setup-esp32s3


注意：ESP32-S3 额外支持主板载灯（WS2812/SK6812）与灯带的独立开关控制。




主要功能

1. WiFi 初始配置（AP + 网页）


首次启动自动进入 AP 模式，广播开放热点

手机/电脑连接热点后通过网页选择 WiFi 并输入密码

配置成功后自动重启并连接家庭 WiFi

支持 WiFi 扫描，自动去重


2. 局域网设备发现（UDP）


主控周期性广播发现包（默认 5 秒一次）

从机收到后上报自身信息（IP、MAC、型号、固件、角色、状态）

支持最多 16 台设备同时在线

超时 8 秒未上报自动判为离线


3. 颜色同步


主控广播颜色指令，所有从机同步变色

支持平滑过渡（默认 200ms）

从机应用颜色后回复 ACK，主控可追踪同步进度

颜色过渡采用浮点插值，效果平滑


4. 分布式锁相快闪


电脑只发一次触发指令，所有设备按统一基准时钟独立执行快闪

基于主控时钟的时间同步（指数平滑滤波），保证相位完全一致

不受网络延迟抖动影响

默认参数：200ms 周期（5Hz）、50% 占空比


5. 网页后台管理


查看本机信息（名称、型号、固件、IP、MAC、角色、分组）

颜色控制（取色器 + 全屏纯色显示）

设备列表（主控模式下显示所有从机）

角色切换（主控/从机）

亮度调节（0-255）

设备名称与分组设置

S3 灯带 / 板载灯独立开关

恢复出厂设置


6. 状态指示（跑马灯）


黄色跑马灯：未注册 + 未连接电脑

红色跑马灯：已注册 + 未连接电脑（断连告警）

正常颜色：已连接电脑并显示当前颜色

红色快闪：满载快闪模式


7. 串口控制


连接电脑的主控板可通过串口接收指令

支持颜色设置、握手探测、恢复出厂、快闪触发等


8. NVS 持久化配置


WiFi 账号密码、角色、名称、分组、亮度等配置保存在 NVS 中

掉电不丢失

恢复出厂时彻底清除（含驱动层残留配置）



快速开始

环境准备


安装 Arduino IDE

安装 ESP32 开发板支持包

安装依赖库：Adafruit NeoPixel
工具 → 管理库 → 搜索 "Adafruit NeoPixel" → 安装


编译烧录


打开 R35050_ESP.ino

在 Arduino IDE 中选择正确的板型：
ESP32C3 Dev Module
ESP32S2 Dev Module
ESP32S3 Dev Module

根据实际灯带长度修改 NUM_LEDS 宏（默认 30）

选择正确的端口，点击上传


首次配网


设备上电后，灯带显示黄色跑马灯，表示未配置

手机/电脑搜索 WiFi 热点（名称见上表），连接该开放热点

浏览器自动弹出配置页面（或手动访问 192.168.4.1）

选择家庭 WiFi，输入密码，点击「连接并保存」

设备自动重启并连接 WiFi，灯带变为红色跑马灯（等待颜色指令）


设置主控


连接设备后，在浏览器输入设备 IP 进入管理页面

在「本机配置」中将角色改为「主控」，点击保存

该设备将成为主控，负责发现从机、广播颜色同步指令

其余设备保持「从机」角色即可



提示：建议使用 ESP32-S2 或 ESP32-S3 作为主控，性能更优。C3 作为主控会有三重确认提示。




用户配置参数

在代码顶部可修改以下常用参数：


#define NUM_LEDS           30      // 灯带 LED 数量

通信协议规范（UDP）

所有 UDP 通信均在端口 55555 上进行，采用统一的二进制包格式。


数据包结构

┌─────────────────────────────────────────────────────────┐
│                      包头 (12 字节)                       │
├────────┬─────────┬─────┬────────┬───────┬──────────────┤
│ magic  │ version │ cmd │ length │  seq  │     crc      │
│ 4 字节  │  1 字节  │1字节│ 2 字节  │2 字节 │    2 字节     │
└────────┴─────────┴─────┴────────┴───────┴──────────────┘
│                      载荷 (可变)                          │
└─────────────────────────────────────────────────────────┘

包头字段说明：


字段	长度	说明
magic	4 字节	固定为 "LDSY" (0x4C 0x44 0x53 0x59)
version	1 字节	协议版本，当前为 1
cmd	1 字节	命令类型
length	2 字节	载荷长度（大端）
seq	2 字节	序列号/同步标识（大端）
crc	2 字节	CRC16 校验（对前 10 字节计算）

命令类型

命令码	名称	方向	载荷	说明
0x01	CMD_DISCOVERY	主控→广播	无	设备发现：谁在线？
0x02	CMD_INFO	从机→主控	DeviceInfo	设备响应：上报自身信息
0x03	CMD_COLOR	主控→广播	ColorCmd	设置颜色
0x04	CMD_COLOR_ACK	从机→主控	无	颜色已应用确认
0x05	CMD_RESET	主控→广播	无	恢复出厂设置
0x06	CMD_TIME_SYNC	主控→广播	TimeSyncCmd	基准时钟同步
0x07	CMD_BLINK	主控→广播	BlinkCmd	开始分布式快闪
0x08	CMD_LED_ONOFF	单播	LedOnOffCmd	S3 LED 开关控制

载荷结构

DeviceInfo（设备信息）：



IP 地址（4 字节）

MAC 地址（6 字节）

角色（1 字节）

状态（1 字节，1=在线）

分组（2 字节）

型号（16 字节字符串）

固件版本（12 字节字符串）

名称（20 字节字符串）

灯带开关状态（1 字节，仅 S3 有效）

板载灯开关状态（1 字节，仅 S3 有效）


ColorCmd（颜色指令）：



R / G / B（各 1 字节）

过渡时长（2 字节，ms）

同步 ID（2 字节）


TimeSyncCmd（时间同步）：



主控时钟基准（4 字节，millis()）


BlinkCmd（快闪指令）：



统一起始时刻（4 字节，主控时钟）

快闪周期（2 字节，ms）

占空比（1 字节，%）


LedOnOffCmd（LED 开关指令）：



目标 MAC（6 字节，全 FF 为广播）

灯带开关（1 字节：0=关，1=开，0xFF=不变）

板载灯开关（1 字节：0=关，1=开，0xFF=不变）



串口协议

连接电脑的主控板通过串口（115200 波特率）接收以下指令：


指令	格式	说明
颜色设置	R,G,B\n	设置颜色（0-255），主控立即执行并广播到所有从机
握手探测	?\n 或 PING\n	回复 OK\n
查询 IP	IP\n	回复当前 IP 地址，未连接返回 0.0.0.0
快闪触发	BLINK\n	进入满载红色快闪模式（分布式锁相）
恢复出厂	RESET\n	清除所有配置并重启

示例：


发送：255,0,0\n    → 所有设备变红
发送：0,255,0\n    → 所有设备变绿
发送：?\n          → 回复 OK
发送：BLINK\n      → 所有设备开始红色快闪

技术细节

功耗策略


主控模式：关闭 WiFi 调制解调器睡眠（WIFI_PS_NONE），保证低延迟同步

从机模式：启用调制解调器睡眠（WIFI_PS_MIN_MODEM），空闲时省电


WiFi 重连机制


连接断开后采用指数退避重连策略

初始延迟 1 秒，每次失败翻倍，最大 60 秒


时间同步算法


从机通过 CMD_TIME_SYNC 接收主控时钟基准

采用指数平滑滤波（7/8 旧值 + 1/8 新值）校准时间偏移

有效滤除网络延迟抖动，保证快闪相位一致


CRC16 校验


采用 CRC-16-CCITT 算法（多项式 0x1021）

初始值 0xFFFF，对包头前 10 字节计算

确保 UDP 通信数据完整性


NVS 命名空间


配置存储在 r35050 命名空间下

同时兼容旧版 custom_5V3 命名空间的清理

恢复出厂时同时清除 WiFi 驱动层的残留配置



常见问题

Q：设备上电后一直显示黄色跑马灯？
A：表示设备未配置 WiFi，请连接设备热点进行配网。


Q：配网成功后显示红色跑马灯？
A：红色跑马灯表示设备已连接 WiFi，但尚未收到颜色指令。请通过串口或网页发送颜色指令。


Q：主控找不到从机怎么办？
A：确保所有设备在同一局域网内，检查 UDP 端口 55555 是否被防火墙拦截。


Q：ESP32-C3 能当主控吗？
A：可以，但 C3 单核 160MHz、SRAM 较小，并发设备多时同步会卡顿，仅建议测试用。正式使用推荐 ESP32-S2 或 S3。


Q：如何恢复出厂设置？
A：网页管理页 → 危险操作 → 恢复出厂设置；或通过串口发送 RESET\n 指令。


Q：S3 的板载灯为什么默认不亮？
A：板载灯默认关闭，可在网页管理页的 LED 开关中手动开启。灯带与板载灯可独立控制。
